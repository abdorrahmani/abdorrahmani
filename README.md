### Go Backend Engineer · Builder · Founder

I build backend systems, developer tools, and infrastructure-oriented products.

My primary focus is **Go**, with **Rust** as another important part of my stack. I'm particularly interested in **distributed systems, networking, APIs, observability, deployment infrastructure, and developer experience**.

## 🚀 What I'm Building

### Phelix

**Developer infrastructure for Go & Rust applications.**

Phelix is a developer platform for **building, deploying, monitoring, and managing** Go and Rust applications.

**Core technologies:**

`Go` · `Rust` · `gRPC` · `Docker` · `Redis` · `MySQL` · `Next.js` · `TypeScript`

**Core capabilities:**

- Application monitoring
- Health checks
- Deployments
- Version management
- Log streaming
- Deployment automation
- Secure agent-to-backend communication
