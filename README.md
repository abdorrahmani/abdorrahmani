## Currently building: Phelix

**A self-hosted deployment and orchestration platform for Go and Rust applications.**
Build, deploy, monitor, and manage your apps on your own servers, without depending on managed cloud platforms.

`Go` · `Rust` · `gRPC` · `Docker` · `Redis` · `MySQL` · `Next.js` · `TypeScript`

### Engineering highlights

- **Zero-downtime deployments:** blue-green and rolling releases through a dedicated proxy daemon, with automatic rollback and a stability-verification window after every rollback
- **Matrix build engine:** parallel builds across multiple Go/Rust toolchain versions and target platforms, with per-combination regression tracking
- **Build Reports:** compiler, duration, cache state, and binary size recorded on every build, with regressions flagged against previous builds, fully offline
- **Docker pipeline:** optimized multi-stage Dockerfiles, multi-arch buildx images, and docker-compose generation with common sidecars
- **Secure by design:** AES-256-GCM encrypted, per-version environment snapshots and secure agent-to-backend communication over gRPC
- **Multi-agent identity model:** multiple isolated agents can run safely on a single host
- **Operations:** health checks, monitoring, log streaming, and version management

[Explore Phelix](https://phelix.anophel.com) · [Source on GitHub](https://github.com/abdorrahmani/phelix)
